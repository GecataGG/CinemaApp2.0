# CinemaApp

CinemaApp е ASP.NET Core MVC приложение с MSSQL база данни и Entity Framework Core.

## Изисквания

Преди да стартирате проекта, уверете се, че имате инсталирани:

- Visual Studio 2022 или по-нова версия
- .NET SDK
- Microsoft SQL Server
- SQL Server Management Studio (по желание, за по-лесна работа с базата)

1. Изтегляне на проекта
Направете и влезте в папката на проекта:
Отворете терминал (cmd) и поставете:

git clone https://github.com/USERNAME/CinemaApp.git
__________________________________________________________________________________
2. Отворете проекта

Отворете .sln файла с Visual Studio.
__________________________________________________________________________________
3. Проверете MSSQL сървъра

Преди да стартирате проекта:

уверете се, че MSSQL Server е пуснат
уверете се, че можете да се свържете към него
проверете connection string-а в appsettings.json

Пример:

"ConnectionStrings": {
  "SqlServer": "Server=YOUR_SERVER_NAME;Database=CinemaAppDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
}

Ако използвате различно име на сървъра, го сменете с вашето.
__________________________________________________________________________________
4. Стартирайте миграциите

Преди първото стартиране трябва да приложите миграциите, за да се създаде базата данни.

Отворете Package Manager Console във Visual Studio и изпълнете:

## Update-Database

Ако проектът използва отделен Data проект, може да се наложи първо да изберете правилния:

Default project: проекта с миграциите
Startup project: уеб проекта
__________________________________________________________________________________
5. Стартирайте приложението

След като:

MSSQL сървърът е пуснат
connection string-ът е правилен
миграциите са приложени

можете да стартирате проекта с:

Ctrl + F5
или
бутона Start от Visual Studio
Важно

Ако приложението не може да се свърже към базата:

проверете дали SQL Server услугата работи
проверете дали connection string-ът е правилен
проверете дали имате достъп до сървъра
уверете се, че базата е създадена успешно след Update-Database

## Полезни команди
Създаване на нова миграция:
Add-Migration InitialCreate

Прилагане на миграциите
Update-Database

Забележка

Проектът няма да работи коректно, ако MSSQL Server не е стартиран или ако няма правилна връзка към базата данни.
